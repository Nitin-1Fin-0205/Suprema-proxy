# MatcherIdentify - Suprema Fingerprint Matcher

C# Console application for 1:N fingerprint identification using Suprema UFMatcher.dll

## Setup Instructions

### 1. Prerequisites
- .NET 6.0 or higher
- UFMatcher.dll from Suprema SDK
- Visual Studio or .NET CLI

### 2. Build the Application
```bash
# Navigate to the MatcherIdentify folder
cd c:\Users\nitin\1Finance\support_backend-\MatcherIdentify

# Build the project
dotnet build --configuration Release

# Or use the build script (PowerShell)
.\build.bat

# Or use the build script (Command Prompt)
build.bat
```
